# The plan

`MPS_Transformation_Plan.md` is the written plan these numbers support ("Three Levers, Three Plans").
It was written alongside the original project folder, so its file references use the old layout:

| The plan says | In this repository |
|---|---|
| `model/closure_model.py` | `mps_model/closure_model.py` and the modules it calls |
| `model/levers.py` | `mps_model/levers.py`, `mps_model/recruitment.py` |
| `model/assumptions.json` | `config/assumptions.json` |
| `outputs/` | `reference_outputs/` (or `results/` after a run) |
| `data/*.md` research notes | `docs/research/` |
| `figures/` | `results/figures/` after a run |
